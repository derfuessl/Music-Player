# Fossify Music Player Kids auf dem Galaxy Tab A8 installieren

1. Öffne das [Release 1.8.5-kids.2](https://github.com/derfuessl/Music-Player/releases/tag/kids-v1.8.5-2). Für das Komplettpaket lade **Fossify-Music-Player-Kids-1.8.5-kids.2.apk** herunter. Du kannst die Datei auch per USB vom PC in den Ordner **Download** auf dem Tablet kopieren (USB-Modus **Dateien übertragen**).
2. Öffne auf dem Tablet **Eigene Dateien → Downloads**, tippe auf die APK und wähle **Installieren** bzw. **Aktualisieren**. Falls Android eine Freigabe verlangt, erlaube die Installation für **Eigene Dateien**. Diese Erlaubnis kann danach wieder ausgeschaltet werden.
3. Öffne **Fossify Music Player Kids** und erlaube den Zugriff auf Musik- und Audiodateien. Für ein Update von `1.8.5-kids.1` verwende dieselbe Variante wie bisher und lasse die bisherige Installation bestehen. Die frühere Debug-Testversion und die anderen Varianten haben eigene App-Daten.
4. Für ein Widget eine freie Stelle auf dem Startbildschirm gedrückt halten, **Widgets → Fossify Music Player Kids** wählen und **Playlist-Liste** oder **Playlist-Kacheln** einsetzen. Im Suchfeld einen Teil des Playlist-Namens eingeben, bis zu sechs Playlists markieren und mit **OK** speichern. Das Cover startet die Musik; der Name öffnet die Titelliste.
